# 音量ボタン(tegra210gpio 1.0.1.0、試験版)

## 直したこと
音量 - の長押しで音量が続けて下がらず、指を離したときに一気に下がることがありました。再起動すると治ります。
- **原因(推定):** ボタンの接点が少しはねる(チャタリング)と、押したときと離したときの 2 つの変化が近すぎて、GPIO の割り込みが 1 回分しか出ないことがありました。音量ボタンのドライバー(Windows 標準の hidinterrupt)は、割り込みのたびに「押した」と「離した」を交互に切り替えます。1 回でも取りこぼすと、Windows を再起動するまで「押した」と「離した」が逆になります。逆になると、押している間は「離した」扱いなので続けて下がらず、離したときに「押した」扱いになって下がります。
- ボタン本体は壊れていません。UEFI のメニューでは、- の長押しで続けて動きました。
- **1.0.1.0 の変更:** 両方の変化をとる、ハードウェアのエッジ検出をやめました。代わりに、今のレベルと逆のレベルを待つ割り込みにして、割り込みのたびに待つレベルを切り替えます。こうすると割り込みは必ず「押した」「離した」の順に交互に出て、実際のボタンの状態とずれません。
- 2 秒ごとに、音量ボタンの回数と状態をレジストリに残します(`Status.cmd` で見られます)。

**SD への書き込みはありません。**

## 入れ方
1. このフォルダーを Switch の Windows にコピーします。
2. `Install.cmd` を右クリックして、「管理者として実行」を選びます。
3. Windows を再起動します。

## 確かめること
1. 音量 - を 3 秒ほど長押しします。押している間、音量が続けて下がることを確かめます。離したときに、まとめて下がらないことも見てください。
2. 音量 + も同じように確かめます。
3. 短く押す、すばやく何度も押す、+ と - を続けて押す、なども試してください。
4. 3 秒ほど何も押さずに待ってから、`Status.cmd` を管理者として実行し、画面を撮ってください。`VOL+` と `VOL-` の行の最後が `OK` なら、ドライバーとボタンの状態は一致しています。`MISMATCH` のときは、その画面を見せてください。

## 元に戻すとき
`Remove.cmd` を管理者として実行し、Windows を再起動します。1.0.1.0 だけを消して、前の版(1.0.0.4)に戻ります。

## もし起動が止まったら
電源ボタンを長押しして切り、もう一度起動してください。それでも止まるときは、そのことを知らせてください。
