# スリープ 段階 a0：今の状態を調べる(読むだけ)

モダンスタンバイ(S0 Low Power Idle)を足す前に、今の Windows がスリープについてどう判断しているかを調べる。
何もインストールせず、電源の設定も変えない。

## S1（2026-11-25）：まとめて測る

- `S1.cmd` をダブルクリック(管理者の確認が出る)。`Report` のあと、`Timer`(画面を 2 分消す)を続けて行う。画面が消えている間は本体に触らない。2 分たっても画面が付かなければ、電源ボタンを 1 回短く押す。
- 終わると、記録 `C:\SwitchWOA-Sleep.txt` を、`share.txt` に書いた PC の共有(`logs\`)へ自動で送る。送れなかったときは `SendLogs.cmd` でもう一度送る。
- どの .cmd も、ダブルクリックで管理者として動く。

## S4（2026-11-26）：画面オフの消費電力を測る

- 先に `..\battery\Install.cmd` で switchbattery 1.0.0.9 を入れる（電池チップの電流を 10 秒ごとに読む。再起動は不要）。
- 充電器を外してから `Drain-10min.cmd` を実行する。画面が 10 分消える。終わっても画面が付かなければ、電源ボタンを 1 回短く押す。
- SUMMARY の `power, screen off: average ... mW` が、画面オフのときの平均消費電力。`- ` はバッテリーから出ている向き。
- 画面が付いているときの電力は、`Report.cmd` の `battery current now` に出る。

## 中身

| ファイル | 内容 |
|---|---|
| `Sleep.ps1` | 調べる本体。`-Mode Report`、`-Mode Drain`、`-Mode Timer` |
| `Report.cmd` | 今の状態を表示する(約 15 秒) |
| `Drain-10min.cmd` | 画面を 10 分消して、CPU のアイドルと電池の減りを測る |
| `Drain-1min.cmd` | 同じことを 1 分だけ(動くかどうかの確認用) |
| `S1.cmd` | `Report` と `Timer` を続けて行い、記録を PC に送る |
| `SendLogs.cmd` | 記録を PC の共有へ送る |
| `Timer-2min.cmd` | 画面を 2 分消して、10 秒ごとに 3 つの時計(ストップウォッチ = QPC、ティック、Windows の時計)を比べる |

どれもダブルクリックで管理者として動く。最後に `SUMMARY` が出るので、その画面を写真に撮る。
記録は `C:\SwitchWOA-Sleep.txt` に追記される。

## Report.cmd で見るもの

- **powercfg /a:** 使えるスリープの種類と、使えない理由(例: グラフィックス、ファームウェア)。
- **Power キー:** `CsEnabled`(モダンスタンバイが有効か)などのレジストリの値。
- **ボタン:** 電源ボタンとスリープボタンの動作(0 何もしない、1 スリープ、2 休止、3 シャットダウン、4 画面オフ)。
- **プロセッサー:** CPU のアイドルが禁止されていないか。画面オフとスリープまでの時間。
- **画面のドライバー:** 基本ディスプレイかどうか。
- **CPU のデバイス:** ACPI0007 が 4 つ見えているか、どのドライバーが付いているか。
- **CPU のアイドル(10 秒):** 各コアの C1/C2/C3 の時間の割合と、1 秒あたりの回数。
  今は WFI しかない見込みなので、C1 だけになるはず。段階 a1(UEFI R406 の `_LPI`)のあとで、C2 が出るかを比べる。
- **電池:** 残量、充電器の有無、電圧。
- **Kernel-Power のイベント:** 最近のスリープ・スタンバイの記録。

## Drain-10min.cmd

- 充電器を外して実行する。
- 始まると画面が消える。10 分のあいだは本体に触らない。
- 30 秒ごとに CPU のアイドルと電池を記録し、最後に画面を付けて結果を出す。
- 30 秒 × 回数で終わる。ただし Switch では画面オフ中にストップウォッチが遅れるので、実際には 10 分より長くかかることがある。電池の減りの割合は Windows の時計で計算する。
- 記録の行の `n/20` が進み具合、`clock` が Windows の時計、`read` が 1 回の読み取りにかかった秒数。
- 残量は 1% 刻みなので、10 分では差が小さい。電圧の差も一緒に見る。

## Timer-2min.cmd

- 1 回目の Drain で、画面が消えている間にストップウォッチ(QPC)が実際の時間より大きく遅れた(31 秒のあいだに実際は 4.6 分)。写真の撮影時刻から、Windows の時計のほうが正しいと分かった。
- このモードは、10 秒待つたびに 3 つの時計がそれぞれ何秒進んだかを出す。どれが遅れるか、待つこと自体が遅れるかを見分ける。
- 画面が消えている間は、本体に触らない。

## 画面の付け方

- 画面が消えているときは、タッチでは付かない(Windows は、画面が消えているときのタッチを無視する。タブレットの普通の動き)。
- 電源ボタンを 1 回短く押すと付く。
- テストが終わると、キットがマウスを 1 ドット動かして画面を付けようとする。それでも消えたままなら、電源ボタンを押す。
