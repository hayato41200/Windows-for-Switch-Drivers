## 変更内容 / What changed

**GPU（GM20B）を使うための準備が入りました。GPU を使う機能は、どれも既定でオフです。**

- **UEFI R447H（hekate 用 bl33）:**
  - ACPI に、GPU の 2 つの割り込み（stall: SPI 157、nonstall: SPI 158）を足しました。GPU ドライバーが、コマンドの完了を割り込みで知るのに使います。
  - ほかは R445H と同じです。
- **switchdisplay 1.8.0（画面）:**
  - GPU のコピーエンジンで画面を転送する道（`GpuPresent`）と、ダブルバッファ（`DoubleBuffer`、vblank で切り替えてティアリングを減らす）を足しました。
  - **どちらも既定でオフ**です。オフのときは、1.7.0 と同じ動き方をします。
  - オンにするには、GPU ドライバー（switchgpu）と、自分で用意した NVIDIA のファームウェア（linux-firmware の `nvidia/gm20b`）が必要です。どちらもこのリリースには入っていません。今はまだ開発用で、ソースの `kits/Switch-Gpu` のキットから入れます。
- ほかのドライバー、コントロールセンター（0.9.2）、SwitchPatcher（0.6.0）は 2026.11.24 と同じです。

**実機で確認したこと:**
- R447H で hekate から Windows が起動し、今までの機能（画面・テレビ・音声・USB・Wi-Fi・BT）が動くこと。
- switchdisplay 1.8.0 で、GPU 機能をオフにしたまま、本体の画面とテレビ（拡張・複製）が今までどおり出ること。
- （開発用キットで）GPU 転送とダブルバッファをオンにすると、ウィンドウを動かしたときのティアリングがほとんど出なくなること。GPU を 10 秒使わないと電源を切り、温度が 49 ℃ から 40 ℃ に下がること。

**まだ確認していないこと:**
- コントロールセンターの更新（OTA）でこのリリースを入れること。
- テレビをつないだ状態での GPU の電源オフ。

**今後実装する予定:**
- GPU ドライバーをリリースに入れて、ファームウェアの取り込みと、GPU 機能のオン・オフをコントロールセンターでできるようにする。
- スリープ（モダンスタンバイ）。

**Groundwork for the GPU (GM20B). Every GPU feature is off by default.**
- UEFI R447H (hekate bl33): ACPI now lists the GPU's two interrupts (stall SPI 157, nonstall SPI 158), which the GPU driver uses for command completion. Otherwise the same as R445H.
- switchdisplay 1.8.0: an optional GPU copy-engine present path (`GpuPresent`) and double buffering with flips at vblank (`DoubleBuffer`, less tearing). Both are off by default, and with them off the driver behaves like 1.7.0. Turning them on needs the GPU driver (switchgpu) and your own NVIDIA firmware (linux-firmware `nvidia/gm20b`); neither is in this release. For now this is for development, from the `kits/Switch-Gpu` kit in the source.
- Other drivers, the control center (0.9.2) and SwitchPatcher (0.6.0) are the same as in 2026.11.24.
- Tested on hardware: booting Windows from hekate on R447H with the existing features working; switchdisplay 1.8.0 with the GPU features off (panel and TV, extend and duplicate); with the development kit, GPU presents plus double buffering remove almost all tearing, and the GPU powers off after 10 s idle (49 °C down to 40 °C). Not tested: installing this release over the air; GPU power-off with the TV attached. Planned: the GPU driver in the release with firmware import and on/off switches in the control center; sleep (modern standby).
