## 変更内容 / What changed

**スタートメニューの「シャットダウン」で、本体の電源が切れるようにしました。**

- **switchpwrbtn 1.0.4.0（電源ボタン）:**
  - 今までは、Windows の高速スタートアップがオンだと、「シャットダウン」が実際には休止状態になっていました。そのため電源が切れず、画面が暗くなったあと本体が起動し直して、ログオン画面に戻っていました。
  - ドライバーが高速スタートアップをオフにしておくようにしました（`HiberbootEnabled=0`、起動時と 10 秒ごとに確認）。これで「シャットダウン」が本当のシャットダウンになり、PMIC で電源を切ります。
  - 高速スタートアップをそのままにしたいときは、`HKLM\SYSTEM\CurrentControlSet\Services\switchpwrbtn\Parameters` の `FastStartup` を 1 にします。
- **電源ボタンのキット（Switch-PowerButton）:**
  - `Status.cmd` に、高速スタートアップの状態と、ドライバーが最後に Windows に任せた電源操作を表示します。
  - `FastStartup-On.cmd` / `FastStartup-Off.cmd`（試験用）を足しました。
  - `Install.cmd` と `Status.cmd` は、ダブルクリックで管理者として実行するようになりました。
- ほかのドライバー、コントロールセンター、SwitchPatcher、UEFI（R445H）は 2026.11.23.3 と同じです。

**実機で確認したこと:**
- 「シャットダウン」で電源が切れること（ファンが止まり、起動し直さない）。
- 「再起動」で、今までどおり hekate を通って Windows に戻ること。

**まだ確認していないこと:**
- コントロールセンターの更新（OTA）でこのリリースを入れること。

**今後実装する予定:**
- 「休止状態」を選んだときは、今も休止ファイルを書いたあと起動し直して復帰します（電源は切れたままになりません）。直すかどうかはこれから考えます。

**Shut down now powers the console off.**
- switchpwrbtn 1.0.4.0: with Windows fast startup on, Start > Shut down was a hybrid hibernate, so the console did not power off: the screen went dark, the console started again and came back to the logon screen. The driver now keeps fast startup off (`HiberbootEnabled=0`, checked at start and every 10 s), so Shut down is a real shutdown and the PMIC powers the console off. Set `FastStartup` = 1 under the driver's Parameters key to leave fast startup alone.
- Power button kit: Status shows fast startup and the last power action left to Windows; FastStartup-On/Off.cmd (test); Install.cmd and Status.cmd ask for administrator through UAC.
- Other drivers, the control center, SwitchPatcher and the UEFI (R445H) are the same as in 2026.11.23.3.
- Tested on hardware: Shut down powers off; restart still goes through hekate back to Windows. Not tested: installing this release over the air. Planned: Hibernate still restarts and resumes instead of staying off.
