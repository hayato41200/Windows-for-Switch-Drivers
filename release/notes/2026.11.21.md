## 変更内容 / What changed

**USB-C のテレビ出力が、1080p と、電源の無いアダプターに対応しました。**

- **UEFI R444H（hekate 用 bl33）:**
  - テレビの EDID に 1920x1080@60 が書いてあれば、1920x1080 で出します。書いていないとき、またはリンクの速さが足りないときは、今までどおり 1280x720 で出します。
  - Switch が USB-C に電気を送っているとき（電源の無い USB-C → HDMI アダプターやハブ）にも、DP Alt Mode に入ります。起動時に USB-C に何かをつないでいると、起動が 2〜4 秒ほど長くなります。
  - R442H からの変更は、この 2 つだけです。
- **switchdisplay 1.5.0:** 1920x1080 のテレビには、1280x720 の絵を表示コントローラーで 1.5 倍に広げて出します。Windows に入ってからの抜き差しでも、テレビに合わせて解像度を選びます。
- **switchbattery 1.0.0.8:** Windows に入ってから電源の無いアダプターをつないだときも、DP Alt Mode に入ります。
- **コントロールセンター 0.9.1:** 更新の種類（安定版・ベータ版）の選択を無くしました。いつも最新のリリースと比べます（ベータ版のリリースは 2026-11-20 に無くしました）。

**実機で確認したこと（hekate の経路）:**
- テレビの入力が 1080p になる。
- 電源をつないだ DP Alt 対応ハブと、電源の無い ELECOM の 4K30 DP Alt アダプターの両方で、起動時から映る。Windows で抜いて、つなぎ直しても映る。
- コントロールセンター 0.9.1 が起動し、更新の確認ができる。

**まだ確認していないこと:**
- 広げた絵をなめらかにする設定（レジストリ `TvFilter` = 1）。ふだんは切ってあります。
- Nintendo 純正のドック。

**今後実装する予定:**
- テレビを2つ目の画面として使う（拡張表示）。今は本体と同じ画面を映すだけです。
- HDMI からの音声。
- Nintendo 純正のドックでの確認。
- 1920x1080 より大きい解像度（今のリンク、2 レーン・2.7 Gbps では 4K は送れません）。

**USB-C TV output now runs at 1080p and works with unpowered adapters.**
- UEFI R444H (bl33 for hekate): 1920x1080@60 when the TV's EDID lists it and it fits the link, else 1280x720 as before; DP Alt Mode also when the Switch powers VBUS (unpowered USB-C to HDMI adapters and hubs). Boot takes about 2–4 s longer when something is plugged into USB-C at boot. Nothing else changed since R442H.
- switchdisplay 1.5.0: on a 1920x1080 TV the 1280x720 picture is scaled up by the display controller; hot-plug in Windows picks the mode too.
- switchbattery 1.0.0.8: enters DP Alt Mode for unpowered adapters plugged in under Windows.
- Control center 0.9.1: no update channel choice any more; always compares with the latest release.

Tested on hardware (hekate chain): the TV input is 1080p; a powered DP Alt hub and an unpowered ELECOM 4K30 DP Alt adapter both work from boot and after re-plugging in Windows; control center 0.9.1 starts and checks for updates.
Not tested: `TvFilter` = 1 (off by default); the official Nintendo dock.
Planned: the TV as a second (extended) display; HDMI audio; a check with the official Nintendo dock; modes above 1920x1080 (the current link, two lanes at 2.7 Gbps, cannot carry 4K).
