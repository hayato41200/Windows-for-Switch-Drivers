## 変更内容 / What changed

**コントロールセンターで、ファンの強さを手動で決められるようにしました。**

- **switchfan 1.0.0.3（ファン・バックライト）:**
  - ファンの強さを、自動のほかに、手動（0〜100%）でも決められるようにしました。
  - 手動の設定はドライバーが覚えているだけなので、Windows を再起動すると自動に戻ります。
  - 68 ℃ 以上になると、手動で低くしていてもファンを 100% にします。65 ℃ 未満になると、手動の強さに戻ります。
  - 温度センサーが読めないときは、今までどおり 65% にします（手動の値のほうが高ければ、手動の値）。
- **コントロールセンター 0.9.2:**
  - 「パフォーマンス」タブに「ファン」の欄を足しました。「ファンの強さを手動で決める」にチェックを入れて、スライダーで強さを選びます。
  - 今の強さ、温度、状態（自動・手動・68 ℃ 以上で 100%・センサーが読めない）を表示します。
  - 概要タブのファンの % に、手動のときは「（手動）」と付けます。
- ほかのドライバー、SwitchPatcher、UEFI（R445H）は 2026.11.23.2 と同じです。

**実機で確認したこと:**
- このリリースを、コントロールセンターの更新（OTA、0.9.1 → 0.9.2）で入れること。
- 手動にしたとき、スライダーのとおりにファンの強さが変わること。
- 自動に戻したとき、元の動きに戻ること。
- 再起動すると自動に戻ること。

**まだ確認していないこと:**
- 68 ℃ 以上で、手動でも 100% になること。

**今後実装する予定:**
- 特になし（実機の結果しだいで直します）。

**Manual fan control in the control center.**
- switchfan 1.0.0.3: the fan can be set by hand (0-100 %) as well as automatically. Manual is kept in memory only, so restarting Windows goes back to automatic. At 68 °C or more the fan runs at 100 % even when manual (released below 65 °C). If the temperature cannot be read, the fan still goes to 65 % (or the manual value if higher).
- Control center 0.9.2: a Fan box on the Performance tab (manual check box, speed slider, current speed, temperature and state). The overview shows "(manual)".
- Other drivers, SwitchPatcher and the UEFI (R445H) are the same as in 2026.11.23.2.
- Tested on hardware: installing this release over the air from the control center (0.9.1 to 0.9.2), manual and automatic fan, going back to automatic after a restart. Not tested: the 68 °C guard.
