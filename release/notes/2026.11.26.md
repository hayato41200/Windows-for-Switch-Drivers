## 変更内容 / What changed

**画面を消している間も、タイマーが時間どおりに動くようになりました（スリープ対応の第一歩）。**

- **UEFI R448H（hekate 用 bl33）:**
  - ACPI の GTDT（タイマーの表）に、タイマーが CPU の休止中も動き続ける印（Always-on Capability）を足しました。
  - これまでは、画面を消すと、タイマーで CPU が起きませんでした。たとえば 10 秒待つ処理が、電源ボタンを押すまで（5 分以上）戻らないことがありました。Windows Update が途中で止まり、更新が中途半端に当たって Windows が壊れたのも、これが原因だと考えています。
  - ほかは R447H と同じです。
- **SwitchPatcher 0.6.1（PC）:**
  - 「ファームウェア」のフォルダーに、自分で用意した linux-firmware の `nvidia\gm20b` があれば、SD の `SwitchWOA\firmware\nvidia\gm20b` に入れます。開発中の GPU キットは、ここからファームウェアを読み込みます。
  - NVIDIA のファイルは、このリリースには入っていません。
- **コントロールセンター 0.9.3:**
  - 「ファームウェア」の取り込みで、同じように `nvidia\gm20b` も `C:\SwitchWOA\firmware\nvidia\gm20b` に入れます。ほかは 0.9.2 と同じです。
- ドライバーは 2026.11.25 と同じです。

**実機で確認したこと:**
- R448H で hekate から Windows（11 23H2、22631.7714）が起動すること。
- 画面を消したまま 10 秒待つ処理を 12 回繰り返して、どれも 10.0〜13.1 秒で戻ること（R447H では 332.7 秒）。2 分たつと、画面が自分で点くこと。
- SwitchPatcher 0.6.1 で Windows 11 23H2 の新しい SD を作り、Switch で起動すること。GPU のファームウェアが `C:\SwitchWOA\firmware\nvidia\gm20b` に入り、GPU キットのインストールが通ること。

**まだ確認していないこと:**
- コントロールセンターの更新（OTA）でこのリリースを入れること。
- コントロールセンター 0.9.3 のファームウェア取り込みで、GPU のファイルを入れること。
- 電池の減り方。CPU は、まだ浅い休止（C1）しか使っていません。

**今後実装する予定:**
- スリープの続き: CPU を深く休ませる（`_LPI`）、本当のスタンバイと電池の測定。
- GPU ドライバーをリリースに入れて、GPU 機能のオン・オフをコントロールセンターでできるようにする。

**Timers now fire on time while the screen is off (first step toward sleep).**
- UEFI R448H (hekate bl33): the ACPI GTDT timer flags now say Always-on Capability. Before, timers did not wake the CPU with the screen off (a 10 s wait could last until the power button, over 5 minutes); we think this also stalled a Windows Update run and left Windows half-updated. Otherwise the same as R447H.
- SwitchPatcher 0.6.1 (PC): if the firmware folder holds your own linux-firmware `nvidia\gm20b`, it is copied to `SwitchWOA\firmware\nvidia\gm20b` on the SD, where the GPU development kit reads it. No NVIDIA files are in this release.
- Control center 0.9.3: its firmware import copies `nvidia\gm20b` to `C:\SwitchWOA\firmware\nvidia\gm20b` the same way. Otherwise the same as 0.9.2.
- Drivers are the same as in 2026.11.25.
- Tested on hardware: Windows 11 23H2 (22631.7714) boots from hekate on R448H; twelve 10 s waits with the screen off took 10.0-13.1 s each (332.7 s on R447H) and the screen came back by itself; a new 23H2 SD made with SwitchPatcher 0.6.1 boots, gets the GPU firmware in `C:\SwitchWOA\firmware\nvidia\gm20b`, and the GPU kit installs. Not tested: installing this release over the air; the control center 0.9.3 firmware import with GPU files; battery drain (the CPU still uses only the shallow C1 idle state). Planned: deeper CPU idle (`_LPI`), real standby with battery measurements; the GPU driver in the release with on/off switches in the control center.
