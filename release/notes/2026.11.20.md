## 変更内容 / What changed

**USB-C のテレビ出力（DisplayPort Alt Mode）に対応しました（ベータ）。**
DP Alt に対応した USB-C ハブ（HDMI 出力つき、電源をつないだもの）で、本体と同じ画面をテレビに 1280x720 で映せます。起動時からつないでいれば UEFI の画面から映り、Windows に入ってからつないでも映ります。本体の向きを変えても、テレビの絵は正立します。

- **UEFI R441H（hekate 用 bl33）:** BM92T で DP Alt Mode に入る、DPAUX1（HPD・DPCD・EDID）、SOR1 のリンクトレーニング（2.7 Gbps x 2）、DC-B と PLLD2（74.25 MHz）、SOR1 のパッドの電源（MAX77620 LDO8）を起動のたびに入れる。R423H からの変更はこの機能だけです。
- **switchbattery 1.0.0.7:** Windows に入ってから DP Alt に対応したハブをつなぐと、DP Alt Mode に入り、switchdisplay に知らせます。
- **switchdisplay 1.4.4（ベータ）:** テレビへの出力と、抜き差しへの対応。あわせて、1.2.0 から起動直後に Windows に止められていた不具合（エラー 43）を直しました。これまでの版では、実際には Windows 標準の Basic Display が画面を描いていました。この版からは switchdisplay が描きます（回転、画面オフでのパネルのスリープなど）。

**今後実装する予定:**
- テレビを2つ目の画面として使う（拡張表示）。今は本体と同じ画面を映すだけです。
- 1280x720 以外の解像度（テレビの EDID から 1080p などを選ぶ）。
- HDMI からの音声。
- Nintendo 純正のドックでの確認（市販の DP Alt 対応ハブで確認しました）。
- 電源の無いハブ・変換ケーブルでの DP Alt Mode。

**USB-C TV output (DisplayPort Alt Mode), beta.** With a USB-C hub that has DP Alt and HDMI and its own power, the built-in screen is mirrored on the TV at 1280x720, from the UEFI screen on (when connected at boot) and also when the hub is plugged in after Windows has started; the TV picture stays upright in every orientation.
- UEFI R441H (bl33 for hekate): DP Alt Mode through the BM92T, DPAUX1, SOR1 link training, DC-B with PLLD2, SOR1 pad rail (MAX77620 LDO8) at every boot. Only this feature changed since R423H.
- switchbattery 1.0.0.7: enters DP Alt Mode when a hub is plugged in under Windows and tells switchdisplay.
- switchdisplay 1.4.4 (beta): TV output and hot-plug; also fixes the stop right after start (error 43) that every version since 1.2.0 had, so Basic Display had been drawing the screen until now.

Planned: the TV as a second (extended) display; modes other than 1280x720; HDMI audio; a check with the official Nintendo dock; unpowered hubs and adapters.
